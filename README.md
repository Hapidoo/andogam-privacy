# Andogam Descent — privacy policy

This repository exists for one reason: App Store Connect needs a **public URL**
for the app's privacy policy, and the game's own repository is private.

The page is published at <https://hapidoo.github.io/andogam-privacy/>.

`index.html` is a copy. The authored source is `docs/privacy.html` in the game's
repository, where it is versioned alongside the app it describes — **edit it
there and copy it here**, rather than editing this file, or the policy Apple
reads and the policy the project believes it has will drift apart.

The page is deliberately self-contained: no scripts, no stylesheets, no images,
no external references of any kind. It is one file that works anywhere.
